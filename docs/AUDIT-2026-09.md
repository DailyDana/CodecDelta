# Denetim — Eylül 2026 (v0.2.0 üzerinde)

ABX'e (kilometre taşı 9) geçmeden önce tüm kod tabanında hata denetimi. Kod
değiştirilmeden yapıldı; dört bölüm paralel incelendi (çekirdek + bitstream,
hizalama + karşılaştırma, psikoakustik + doğrulama + rapor, arayüz + kodlama),
kritik iddialar ayrıca yeniden üretildi.

**Kanıt etiketleri:** DOĞRULANDI = çalıştırılarak yeniden üretildi · OLASI =
mekanizma kodda görülüyor, üretilmedi · KANITLANMADI = şüphe.
**Kaynak:** *yeniden* = denetimi yöneten tarafından bağımsız yeniden üretildi ·
*ajan+kod* = alt denetimde üretildi, mekanizma kod okunarak doğrulandı ·
*ajan* = yalnızca alt denetimde üretildi.

Durum sütunu düzeltmeler ilerledikçe güncellenir.
